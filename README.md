# Dental Radiograph Pipeline

End-to-end dental radiograph analysis: detection → segmentation → grounded report generation.

## Highlights
- Tooth and pathology detection with YOLOv8
- Segmentation-guided findings feed a grounded LLaMA3 report generator
- Voice interaction via Faster Whisper and a clinician-facing GUI

## Tech Stack
YOLOv8 · LLaMA3 · Faster Whisper · GUI
